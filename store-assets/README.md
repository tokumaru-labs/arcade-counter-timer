# Store assets

Everything here is generated by scripts in `scripts/`, so it can be rebuilt from
source at any time. All artwork is original to this project.

| File | Size | Purpose | Built by |
| --- | --- | --- | --- |
| `store-icon-128.png` | 128×128 | Store icon | `npm run icons` (copy of `assets/icons/icon128.png`) |
| `small-promo-440x280.png` | 440×280 | Small promo tile (required) | `scripts/build-store-promos.ps1` |
| `marquee-promo-1400x560.png` | 1400×560 | Marquee promo tile (optional) | `scripts/build-store-promos.ps1` |
| `screenshot-main-1280x800.png` | 1280×800 | Main screenshot | `npm run store-assets` |
| `screenshot-stats-1280x800.png` | 1280×800 | Statistics screenshot | `npm run store-assets` |
| `source/popup-main.png` | 360×540 | Raw capture of the popup | `npm run capture` |
| `source/popup-stats.png` | 360×540 | Raw capture of the statistics screen | `npm run capture` |

## How the screenshots were made

`npm run capture` renders the shipped `popup.html`, `popup.css`, `popup.js` and
`src/` modules in headless Chrome and screenshots them at the real popup size of
360×540. The UI in these images is the actual extension, drawn by the actual
code — not a mock-up, and not retouched.

Two things are supplied to make the capture possible and useful:

1. **A `chrome.storage.local` shim.** That API does not exist outside an
   installed extension, so the popup could not start without it. The shim is a
   plain in-memory object with the same three methods.
2. **A sample session.** The shim seeds a timer that has been running for
   12 minutes 34 seconds, a session count of 18, and a few months of daily
   history. Every figure on the statistics screen is then computed by the
   extension's own aggregation code from that history — the numbers are real
   output, not typed into the image.

`npm run store-assets` only scales the 360×540 capture uniformly and places it
on a 1280×800 background beside some copy. The popup itself is never stretched,
cropped, recoloured or edited.

## Re-capturing from an installed extension

If you would rather ship screenshots taken from a real Chrome install:

1. Load the extension via `chrome://extensions` → Load unpacked.
2. Use it normally, so the statistics reflect genuine work.
3. Screenshot the popup at exactly 360×540 with no browser chrome.
4. Save the images as `source/popup-main.png` and `source/popup-stats.png`.
5. Run `npm run store-assets`.

The compose script requires both source files to exist and to be exactly
360×540. If either is missing it stops with an error rather than producing a
placeholder.

## Rebuilding everything

```
npm run icons          # assets/icons/*.png and store-icon-128.png
npm run capture        # source/popup-*.png (needs Chrome or Edge)
npm run store-assets   # screenshot-*-1280x800.png
powershell -ExecutionPolicy Bypass -File scripts/build-store-promos.ps1
```
