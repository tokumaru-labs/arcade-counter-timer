## Detailed description

```
Arcade Counter Timer は、カウントアップタイマーとカウンターをまとめた拡張機能です。ツールバーのポップアップ、Webページ内の自由配置、Chromeのサイドパネルから表示場所を選べます。

■ 6つのテーマ、共通の記録
アイボリーの計器が並ぶ Space Age、ネオンの Arcade、白黒の Editorial、パタパタ表示の Steampunk、深緑と金の Art Deco、ガラス管が光る Nixie。見た目を変えても、タイマー・カウント・記録は共通です。画像とフォントは同梱し、オフラインで使えます。

■ UNDOは繰り返し使えます
押し間違えたCOUNTを、新しい順に何回でも取り消せます。保存された操作履歴が対象です。カウントと元の記録日の統計を一緒に戻し、タイマーは巻き戻しません。画面を閉じても、Chromeを再起動しても取り消し履歴を保持します。取り消した後のCOUNTは新しい操作として追加。タイマー・カウント・セッションのリセットでは取り消し履歴を消し、開始・停止やテーマ変更では保持します。旧版に残る1件の取り消しは引き継げますが、過去の合計から古い操作を復元することはありません。

■ 時間を計る、数を重ねる
START／STOPで計測を操作。100時間を超えても表示でき、画面を閉じても計測は続きます。COUNTは1回の入力で1だけ増加。任意の効果音と短い節目演出で、作業に少し手応えを加えます。歯車ボタンから日・週・月・年の合計、現在時刻の時計、各種演出を設定できます。

■ 表示する場所も自由に
ポップアップ、ドラッグして固定できる自由配置、開いたまま使えるサイドパネルに対応。別のページへ自由配置する場合は、そのページで拡張アイコンを押します。Chrome設定やウェブストアなどの保護されたページには配置できません。各画面のタイマー・カウント・統計は同期します。

■ キーボードとリセット
タイマーにフォーカスがあるとき、Enterで開始・停止、Spaceでカウント、Rの長押しでセッションリセット。TabでUNDOへ移動し、Space／Enterで取り消せます。リセットボタンは長押し式。短いクリックでは動作しません。リセットしても累積統計は残りますが、取り消し履歴は消去されます。CLEAR ALL DATAは確認付きです。動きを減らす設定にも対応します。

■ 記録は端末内へ
同じ拡張機能の通常更新では記録と設定を保持し、更新後の案内は一度だけ表示します。アンインストールするとローカル記録が消えるため、既存の拡張機能をそのまま更新してください。

アカウント、広告、解析、クラウド同期、リモートコード、使用中の外部通信はありません。storageは記録の保存、activeTab／scriptingはユーザー操作による自由配置、sidePanelはサイドパネルに使用。常時のサイトアクセス権限はなく、ページ本文・フォーム・閲覧履歴を抽出しません。

無料・オープンソース。基本の操作ラベルは英語です。GPL-3.0-only。画像・フォントにはそれぞれ記載のライセンスが適用されます。
```
